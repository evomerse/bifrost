        Heimdall, l’assistant

        Un assistant IA qui peut réaliser des tâches sur cet ordinateur (vider la corbeille, vérifier les mises à jour, lire l’espace disque…). Il fonctionne avec votre propre clé API : rien ne passe par un serveur Bifrost.

        Obtenir une clé Groq Cloud (gratuite) en 2 minutes

        1. Cliquez sur (console.groq.com).
        2. Connectez-vous ou créez un compte (e-mail, Google ou GitHub). L’offre gratuite suffit.
        3. Cliquez sur Create API Key, donnez-lui un nom (par exemple « Bifrost ») puis validez.
        4. Copiez la clé affichée : elle commence par gsk_ et n’est montrée qu’une seule fois.
        5. Collez-la dans le champ « Clé API » ci-dessus, puis « Enregistrer la clé ». Le fournisseur par défaut est déjà Groq.

        Obtenir une clé API

        Créez une clé sur le site du fournisseur, puis collez-la ci-dessus.

        Utiliser Claude Code

        Aucune clé à saisir : Heimdall se sert du programme claude déjà installé et connecté sur ce PC (npm install -g @anthropic-ai/claude-code, puis lancer claude une fois pour vous connecter).

        La clé est enregistrée chiffrée par le coffre du système. Heimdall ne peut utiliser que des outils précis, et vous demande confirmation avant toute action qui modifie l’ordinateur.
